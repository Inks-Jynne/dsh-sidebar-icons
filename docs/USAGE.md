# 使用文档

面向"装上之后怎么用"。设计与实现细节见 [DETAIL.md](DETAIL.md)，版本变化见 [CHANGELOG.md](CHANGELOG.md)。

---

## 1. 装上之后先确认这三件事

1. 左侧栏的**项目**行显示的是黏土文件夹（不再是官方那个线框文件夹）；
2. **会话**行左侧的 16px 格子里显示黏土小图标（不是官方状态点）；
3. 项目/会话行的 `⋯` 菜单里能看到 **自定义图标…**。

三条都成立 = 插件工作正常。任一条不成立，跳到第 6 节。

---

## 2. 自动匹配：名字决定图标

图标的初值只看名字，不需要你配：

| 名字里有 | 得到 |
|---|---|
| `api` `接口` `server` | 接口（青，六边形节点） |
| `web` `site` `前端` `页面` | 前端（蓝，地球/窗口） |
| `fix` `bug` `修复` | 修复（珊瑚红，瓢虫）——优先级最高 |
| `release` `deploy` `发布` `上线` | 发布（橙，火箭） |
| `test` `spec` `测试` | 测试（薄荷绿，烧瓶+对勾） |
| `docs` `readme` `文档` | 文档（粉，折角纸） |
| `data` `sql` `数据` | 数据（橙黄，柱状图） |
| `course` `paper` `学习` `english` | 学习（紫，半开书） |
| `chat` `讨论` `会话` | 讨论（天青，气泡） |
| `demo` `原型` `sandbox` `lab` | 实验（紫，立方体） |
| `mobile` `安卓` `ios` `小程序` | 移动（玫红，手机） |
| `security` `密钥` `权限` `漏洞` | 安全（绿，盾牌） |
| `perf` `性能` `优化` `卡顿` | 性能（绿，仪表盘） |

完整关键词表在 `client.js` 的 `PROJECT_RULES` / `SESSION_RULES` 里，**先匹配先赢**，顺序是有意的
（比如同时含 "course" 和 "test" 判为学习，而不是测试）。

> 项目的颜色还多一条规则：**新项目不会和它上面那个项目同色**，会沿色相环往下顺一位——
> 所以同一批项目颜色是均匀铺开的。

## 3. 手动指定某一个图标

1. 鼠标移到那一行，点右侧 `⋯`（项目行和会话行都有）；
2. 菜单里点 **自定义图标…**；
3. 面板里点你想要的那个——**点完立刻生效并关闭**，不用再确认。

面板长什么样：

| | 项目面板 | 会话面板 |
|---|---|---|
| 数量 | 21 个（3 行 × 7 列） | 28 个（4 行 × 7 列） |
| 样式 | 纯色块，名称在悬停提示里 | 图标 + 英文名 |
| 打开时选中 | 这一行**当前正在用**的那个 | 同左 |

底部按钮：

- **Use default**：清掉你设过的自定义，回到按名称匹配（只有设过自定义时才出现）；
- **Done**：关闭。

---

## 4. 选择的存放与同步

- 存在**这个浏览器**的 `localStorage`，键 `dsh-sidebar-icons:overrides`，
  结构 `{ sessions: { <sessionId>: <kind> }, workspaces: { <workspaceId>: <kind> } }`；
- 重启 DSH 不会丢；
- **不跟随会话同步**：换设备、换浏览器 profile、或把会话发给别人，图标回到自动匹配；
- 不写会话日志、不改项目注册表——所以删掉插件不会留下任何残留数据（除了那条 localStorage）。

想一次性清空：

```js
localStorage.removeItem('dsh-sidebar-icons:overrides')
```

## 5. 侧栏层级

会话行相对它所属的项目**右移 16px**，左侧有一条跟着主题走的细引导线：

- 缩进量在一条 CSS 变量里：`--dsi-session-indent`（默认 16px，想改大改小改它）；
- 多层嵌套（项目里还有项目）时，每加一层再 +12px，是宿主自己的层级变量在管；
- 引导线只覆盖会话行，止于最后一条会话。

会话行右侧的**收藏星标已经隐藏**（收藏仍在 `⋯` 菜单第一项）。原因是它原本会盖住左边的图标。

## 6. 出问题先看这里

**图标全是官方的，一点没变**

- 插件列表里 `dsh-sidebar-icons` 是否启用；bundle 开关关一次再开一次。
- 如果刚改过 `client.js`，热重载偶尔不生效：刷新窗口（Ctrl+R）。

**图标变了，但 `⋯` 里没有「自定义图标…」**

- 这是菜单注册没成功。旧版本（≤1.6.0）在冷启动时会踩这个坑，1.6.1 已修；
  确认版本号 ≥ 1.6.1。

**点「自定义图标…」没反应**

- 2.3.0 修过一次（面板取色时读到了未定义的黏土条目导致渲染崩溃）。确认版本 ≥ 2.3.0。
- 仍无反应的话，打开开发者工具看 Console 是否有报错，报错信息足够定位。

**某一行的图标不显示**

- 会话状态不是 idle 时，那个格子显示官方状态点（运行中 / 等待回答 / 未读完成），这是官方行为；
- 已归档的行该格子本来就是空白。

**缩进 / 引导线 / 星标在别的插件更新后错位**

- 这三段是冲着当前官方行结构（`[data-row-key]`、`.sessionRow`、`.rowActions`）和
  `@michengai/dsh-archive-manager` 的 DOM 写的。宿主或该插件大改时，需要复核对位；
  实在不行可以先注释掉 `client.js` 里对应的 CSS 段（有注释标明）。

---

## 7. 卸载

1. 插件管理里停用 / 关掉 bundle；
2. 删掉 profile 里 `node_modules/dsh-sidebar-icons` 的软链或目录；
3. 从 `cordis.patch.yml` 里移除 `sidebar-icons` 那条插入。

停用后所有装饰节点、属性、样式表都会被移除，侧栏回到官方外观。
