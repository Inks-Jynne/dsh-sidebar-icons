# Changelog

版本号跟着 `package.json` 走，日期用本地时间（YYYY-MM-DD）。

## 1.0.1 — 2026-11-27

- **修复**：某个项目行的文件夹图标整块消失（示例：GongTu 与 ChaoXing_Paper 都落到 paper）。
  原因是 v1.0.0 里 <defs> 的 id 按 kind 生成，同一 kind 出现两次就产生**重复 id**，
  url(#…) 解析到另一份（或被移除的）定义，渐变没上色，整块图标变空白。
  现在每次创建实例都生成唯一 id；带 id 的图标不再缓存，纯路径的 16px 字形仍然缓存。
- **加固**：装饰失败时（抛错或画不出来）会把官方文件夹图标放回去，不再留空白格。
## 1.0.0 — 2026-11-27

第一个公开发布版本。

- **21 个项目图标**：黏土文件夹（大圆角本体 + 左上标签页 + 奶油白纸页），按目录名自动匹配 21 个色相，
  新建项目不会和上一个撞色。
- **28 个会话图标**：面板里是黏土 3D 物体，侧栏 16px 行里换成同一套语义的粗线字形；
  按标题自动匹配，分 6 个功能色系 + 1 个中性色。
- **逐行自定义**：项目 / 会话的 `⋯` 菜单 → **自定义图标…**，3×7 / 4×7 面板点选即生效，
  选择存本机 `localStorage`；面板支持焦点陷阱、方向键与 Esc。
- **层级**：会话行相对所属项目右移 16px，带一条跟随主题的细引导线，多层嵌套按宿主层级递增。
- **不打扰宿主**：只追加自己的节点与属性，卸载时全部还原；收藏星标不在行内显示（入口在 `⋯` 菜单）。
- **可维护**：`scripts/check.mjs` 零依赖自检（三张表一致性、规则重复、渲染冒烟与尺寸分档、
  版本与文档一致、文案同键），CI 每次 push 跑同一套。
